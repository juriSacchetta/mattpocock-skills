disable-model-invocation: true
---

Adapted from Matt Pocock's handoff workflow. Save a handoff in the OS temporary directory unless the user chose another location. Include objective, authorization, spec/ticket pointers, integration branch and commit, active or terminal agent states, retained worktrees/branches, completed validation and the next action. Reference existing artifacts rather than duplicating them. Redact secrets and personal data. Distinguish unknown or still-running work from completed work. Recommend only relevant installed skills by their Pi names.
